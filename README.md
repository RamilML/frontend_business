# 📦 «ФФ Ассистент» — WMS & Fulfillment Management System for Wildberries

Полнофункциональная система для фулфилмент-складов: сканирование штрихкодов товаров, распределение по коробкам на разные склады Wildberries, генерация Актов выполненных работ (на 13 стандартных услуг) и хранение документов с выгрузкой в Excel, Word и PDF.

---

## 🏛 Архитектура проекта (Монорепозиторий)

```text
frontend_business/
├── backend/                   # 🐍 Бэкенд на Python (FastAPI + SQLAlchemy + SQLite/Postgres)
│   ├── app/
│   │   ├── api/v1/            # API эндпоинты (auth, clients, shipments, acts)
│   │   ├── core/              # JWT безопасность, конфиг, БД
│   │   ├── models/            # Модели SQLAlchemy (User, Client, Shipment, Act)
│   │   ├── schemas/           # Pydantic схемы валидации
│   │   ├── services/          # Сидирование начальных данных (seed_data)
│   │   └── main.py            # Точка входа FastAPI приложения
│   ├── requirements.txt       # Зависимости Python
│   ├── test_api.py            # Интеграционные тесты API (100% покрытие)
│   └── run.py                 # Скрипт запуска сервера на http://localhost:8000
├── src/                       # ⚛️ Фронтенд на React 18 + TypeScript + Vite
│   ├── components/
│   │   ├── auth/              # Вход, переключатель ролей, модалка API
│   │   ├── clients/           # Справочник и карточки контрагентов
│   │   ├── scanning/          # Сканер ШК под ТСД (звук, вибро, камера)
│   │   ├── packing/           # Упаковка в коробки и склады WB
│   │   ├── acts/              # Генератор Акта на 13 услуг
│   │   ├── documents/         # Единый реестр выгрузок (Excel, Word, PDF)
│   │   └── dashboards/        # Рабочие столы 4 ролей (Оператор, Менеджер, Клиент, Админ)
├── API_CONTRACT.md            # Спецификация REST API контракта
├── docker-compose.yml         # Запуск всей системы в Docker контейнерах
└── package.json
```

## 🚀 Быстрый запуск

### Вариант 1: Запуск в локальном окружении

#### 1. Запуск Бэкенда (FastAPI):
```bash
# Переходим в папку бэкенда
cd backend

# Создаем виртуальное окружение и ставим зависимости (если еще не создано)
python3 -m venv venv
./venv/bin/pip install -r requirements.txt

# Запускаем сервер
./venv/bin/python3 run.py
```
* Бэкенд запустится на: `http://localhost:8000`
* 📖 Интерактивная документация Swagger UI: `http://localhost:8000/docs`

#### 2. Запуск Фронтенда (React + Vite):
В соседней вкладке терминала в корне проекта:
```bash
npm run dev
```
* Фронтенд откроется на: `http://localhost:3000`

---

### Вариант 2: Запуск через Docker Compose одной командой

```bash
docker-compose up --build
```

| Роль | Логин | Пароль | Описание |
| :--- | :--- | :--- | :--- |
| **Оператор** | `operator` | `123456` | Рабочее место сканирования ШК и упаковки на ТСД |
| **Менеджер** | `manager` | `123456` | Полный контроль поставок, контрагентов и генерация актов |
